# Pixel Loom

无需后端的像素动画编辑器。直接打开 `index.html`（或 `npm start` 后访问 http://127.0.0.1:8901）即可使用。

## 功能

- 像素画笔 / 橡皮擦 / 取色 / 填充（真实泛洪填充）
- 帧管理、洋葱皮、本地自动保存和 PNG 导出
- **对称绘画**：水平轴、垂直轴、四向（双轴）三种模式；拖动画布上的 ● 轴柄可把对称轴吸附到格线或格心，拖动期间立即生效，画笔、橡皮、填充都按当前轴同步落点
- **无缝画布**：开启「边缘回卷」后，靠边笔画跨缝连续、填充按环面（torus）泛洪，环绕到对侧
- 轴位、回卷状态、对称模式与每帧像素共用同一条撤销/重做历史（Ctrl+Z / Ctrl+Shift+Z）；切帧、播放、刷新恢复均保持同步
- 导出的 PNG 即画布本身（内部 16×16 位图），与预览逐像素一致，不含轴线/网格

## 结构

- `index.html` — 界面与 DOM 事件绑定
- `loom.js` — 纯逻辑核心：镜像几何、回卷、笔画插值、环面填充、历史与存档（无 DOM 依赖）
- `test/model.test.js` — 核心逻辑测试（轴线边界、连续拖动、环面填充、四向、撤销恢复、存档往返）
- `test/e2e.test.js` — 抽取 `index.html` 内联脚本，在桩 DOM 中真实执行的端到端测试（指针手势、轴柄拖动、刷新恢复、播放等）
